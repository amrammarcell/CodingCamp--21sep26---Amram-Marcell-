# Expense & Budget Visualizer
### Mini Project — RevoU CodingCamp (Amram Marcell)

A mobile-friendly web app to track daily spending, built with pure HTML, CSS, and Vanilla JavaScript — no frameworks, no backend.

---

## Features

- **Add Transactions** — record item name, amount, and category (Food, Transport, Fun)
- **Total Balance** — auto-updates in real time at the top of the page
- **Transaction History** — scrollable list with newest-first ordering and delete support
- **Pie Chart** — visual spending distribution by category via Chart.js
- **Sort Transactions** — by date, amount (asc/desc), or category (A–Z)
- **Persistent Storage** — all data saved to browser Local Storage, survives page refresh

---

## Tech Stack

| Layer | Technology |
|---|---|
| Structure | HTML5 |
| Styling | CSS3 (mobile-first, responsive) |
| Logic | Vanilla JavaScript (ES6+) |
| Chart | Chart.js 4.4.3 (CDN) |
| Storage | Browser LocalStorage API |
| Hosting | GitHub Pages |
